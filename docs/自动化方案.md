# 自动化方案：从采集到发布的五条流水线

原则：**能半自动先半自动**，先跑通"发布 + 数据回流"，再上"采集 + 拆解"。

## 流水线 1：爆款采集（半自动 → 全自动）
- 做法：浏览器自动化（Playwright/已装好的浏览器 MCP）打开平台搜索页 → 按点赞排序 → 抓列表（标题、作者、点赞、链接）
- 难点：平台有反爬（登录态、滑块）。对策：用已登录的浏览器、限速抓取、只抓榜单页
- 输出：`data/爆款池_YYYYMMDD.csv`
- 自动化度：★☆☆（初期人工点，稳定后定时跑）

## 流水线 2：爆款拆解（AI 辅助）
- 做法：下载视频 → 语音转文字（本地 ASR）→ 抽首帧/字幕 → 大模型按"钩子/结构/情绪/引导"四维打分
- 输出：每条一段结构化拆解，汇总成"模板库"
- 自动化度：★★☆（下载环节需人工，分析可全自动）

## 流水线 3：脚本生产（AI 批量生成）
- 做法：模板 × 选题库 → 大模型批量出脚本（钩子 3 版、口播稿、字幕、标题、话题标签）
- 加"合规检查"：医疗功效词、绝对化用语过滤（平台限流重灾区）
- 自动化度：★★★（几乎全自动，人只做终审）

## 流水线 4：剪辑（模板化）
- 做法：剪映模板固定（片头钩子卡 + 跟练分段 + 结尾引导），只换素材和字幕
- 自动化度：★★☆（批量导入素材可脚本化，成片仍需人工看一遍）

## 流水线 5：四平台分发 + 数据回流（已跑通一半）
- 现状：抖音/快手/小红书/视频号发布流程已用 GUI 自动化跑过（有坑：文件选择框、草稿态误判）
- 待补：
  - 发布后**自动截图存证**（确认作品真的上线，不再"存成草稿"）
  - **每日定时抓播放数据**（创作者后台 → 写入 `data/播放数据.csv`）
  - 数据看板：按平台/日期/作品汇总，自动算完播率、互动率
- 自动化度：★★☆（当前，目标是全流程无人值守日更）

## 落地顺序（建议）
1. 本周：发布后自动核验 + 每日数据抓取（收益最直接，能立刻指导选题）
2. 下周：爆款池采集（先跑抖音一个平台）+ 模板库初版
3. 之后：脚本批量生成 + 拆解 AI 化

## 风险
- 平台反爬/封号：所有自动化必须限速、模拟人工、不在同一时间高频操作
- 内容合规：健康类内容避免"治疗/根治"等词
- 账号安全：密码/token 不写进仓库
