# 向爆款学习：闭环工作流

核心思路：**不靠灵感，靠数据逆向工程**。每条爆款都是一次已完成的实验，我们要做的是批量拆解、提炼模板、复用结构。

## 一、学习闭环（5 步）

1. **找样本**：在目标平台搜关键词，按"点赞/播放"排序，取前 50 条；同时锁定 10 个对标账号（1万-50万粉，成长快的）
2. **存样本**：链接、播放、点赞、评论、发布时间、时长、话题标签 → 统一进 `data/` 表格
3. **拆结构**：逐条拆"前3秒钩子 / 中段节奏 / 结尾引导 / 字幕样式 / BGM / 封面文字"
4. **提炼模板**：把重复出现的结构抽象成 5-8 个可复用脚本模板
5. **复用+测试**：同模板换选题批量生产，2 小时看数据，24 小时决定是否加量

## 二、拆解颗粒度（每条必填）

| 维度 | 记录内容 |
|------|----------|
| 钩子 | 前 3 秒原话、画面、是否有字幕大字 |
| 结构 | 分段（0-3s/3-15s/15s-结尾）各讲什么 |
| 时长 | 秒数（太极类 30-60s 为主） |
| 视觉 | 机位、景别、字幕位置、配色 |
| 听觉 | BGM 类型、有无配音、语速 |
| 标签 | 话题数量与类型 |
| 数据 | 播放/点赞/评论/收藏/转发 + 发布时段 |

## 三、太极赛道可参考的爆款母题
- 跟练式（0基础 3 分钟跟练）
- 功效式（失眠/肩颈/三高，痛点直给）
- 反差式（老年人身体状态 vs 年龄）
- 纠错式（"90%的人练错了"）
- 情感式（父女/师徒/传承）

## 四、判断标准（别自嗨）
- 完播率 > 30%：钩子和节奏合格
- 点赞率 > 3%：内容价值合格
- 评论率 > 0.5%：有争议或共鸣
- 涨粉/播放 > 0.5%：有账号价值
