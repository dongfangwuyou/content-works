# 资源地图：到哪里找素材与数据

## 一、平台官方（免费，优先用）

| 平台 | 工具 | 能拿到什么 |
|------|------|-----------|
| 抖音 | 巨量算数（trendinsight.oceanengine.com） | 关键词热度、人群画像、内容趋势 |
| 抖音 | 创作服务中心 → 热点宝 | 实时热点、同类爆款视频榜 |
| 抖音 | 创作者中心后台 | 自己作品的完播率、粉丝画像、流量来源 |
| 快手 | 磁力金牛 / 快手创作者中心 | 作品数据、热门话题 |
| 小红书 | 蒲公英 / 创作中心 | 笔记数据、搜索热词 |
| 视频号 | 视频号助手（channels.weixin.qq.com） | 播放、完播、转发、粉丝画像 |
| 微信 | 微信指数 | 关键词热度趋势 |

## 二、第三方数据（付费，先白嫖免费额度）

- **蝉妈妈**（抖音）：销量榜、视频榜，有免费榜单页
- **新抖 / 飞瓜数据**：抖音账号、视频排行
- **灰豚数据**：快手/小红书
- **千瓜数据**：小红书专用（免费版可看榜单）
- 用法：只用来"找对标账号 + 看爆款列表"，不需要买全套会员

## 三、素材与工具（生产端）

- **免费商用素材**：Pexels、Pixabay、Mixkit（BGM/空镜）
- **国风BGM**：抖音音乐库（站内最安全，不会被限流）
- **剪辑**：剪映（批量模板、自动字幕、一键成片）
- **图文/封面**：Canva、稿定设计（固定模板 → 保持视觉统一）
- **文案辅助**：WorkBuddy 内置大模型（脚本、标题、话题标签批量生成）

## 四、对标账号怎么找（3 个渠道）

1. 平台搜索"太极/八段锦/养生" → 按"最多点赞"筛选 → 记录前 20 个账号
2. 爆款视频的评论区 → 同赛道账号常在评论区互动，顺藤摸瓜
3. 第三方榜单（蝉妈妈/千瓜）→ 选 1万-50万粉、近30天涨粉快的账号

## 五、数据沉淀
所有采集结果统一进 `data/` 目录（csv/json），字段统一，方便后续自动分析。
