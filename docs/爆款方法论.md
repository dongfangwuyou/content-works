# 爆款短视频方法论（太极赛道）v1

> 基于首日数据（抖音1200+/快手800+/视频号200+/小红书100+）的迭代版本，持续更新。

## 一、爆款公式

**爆款 = 钩子(前3秒) × 内容密度 × 情绪共鸣 × 互动引导**

1. **前 3 秒钩子**：决定 70% 的完播率
   - 悬念式："50岁大爷练这个动作，体检报告吓医生一跳"
   - 反差式：慢动作太极 × 快节奏剪辑
   - 痛点式："失眠、肩颈痛？这套太极功法睡觉前 3 分钟搞定"
2. **内容密度**：每 5~8 秒一个信息点/镜头切换，不给划走的机会
3. **情绪共鸣**：健康焦虑、传统文化认同、家庭情感（爸妈练太极）
4. **互动引导**：结尾抛问题 + 评论区置顶引导（"你练到第几天了？"）

## 二、平台差异打法

| 平台 | 关键指标 | 打法 |
|------|----------|------|
| 抖音 | 完播率、互动率 | 强钩子+快节奏；蹭热点话题 #太极 #健康 #养生 |
| 快手 | 老铁关系、关注转化 | 人设化、口语化、连续剧式更新 |
| 小红书 | 收藏率 | 干货教程式封面+标题（"收藏起来慢慢练"） |
| 视频号 | 转发率 | 中老年友好、家庭转发场景（"转给爸妈"） |

## 三、选题库（可持续产出）

- 【跟练系列】每天一式：起势→野马分鬃→白鹤亮翅…（天然日更连载）
- 【功效系列】太极对失眠/三高/肩颈的作用（蹭健康流量）
- 【故事系列】60岁开始学太极的真实变化
- 【误区系列】"这样练太极反而伤膝盖"（争议=评论）
- 【热点结合】节气养生 × 太极（二十四节气日更）

## 四、数据复盘节奏

- 每条视频发布后 2h / 24h / 72h 记录播放、点赞、评论、完播
- 播放 <500：钩子问题，换前3秒
- 播放高但互动低：结尾互动引导要加强
- 完播率高但播放低：发布时间/标签优化（晚上 19:00-21:00 黄金档）

## 五、发布检查清单

- [ ] 标题带 1 个钩子词 + 2~3 个话题标签
- [ ] 封面统一风格（字体大、字幕清晰，中老年可读）
- [ ] 前3秒无废话
- [ ] 评论区置顶引导语
- [ ] 四平台同步，各平台微调标题
